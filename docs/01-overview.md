# Project Overview

## Project Description

This project consists of the design and implementation of a secure remote-access VPN infrastructure for a small business.

The solution uses WireGuard running on Ubuntu Server to provide encrypted connections between authorized remote users and the company's internal network.

The main purpose of the project is to allow employees to securely access internal corporate resources from remote locations while maintaining centralized access control and reducing the risk of unauthorized access.

## Objectives

The main objectives of the project are:

- Provide secure remote access to internal corporate resources.
- Encrypt communications between remote users and the corporate network.
- Restrict VPN access to authorized users and devices.
- Centralize VPN access management.
- Provide a solution that can be maintained and scaled according to the company's needs.
- Use open-source technologies to keep implementation and maintenance costs low.

## Technologies

The main technologies used in the project are:

- Ubuntu Server
- WireGuard
- Linux
- Network routing and firewall rules
- WireGuard clients for remote devices

## Scope

The project covers the design and implementation of the VPN infrastructure, including:

- Requirements analysis.
- Network architecture design.
- VPN network configuration.
- WireGuard server deployment.
- Client configuration.
- Access control.
- Connectivity and security testing.
- Basic monitoring and maintenance procedures.

## Expected Result

The expected result is a functional VPN infrastructure that allows authorized remote users to establish secure connections with the company's internal network.

The infrastructure is designed to provide a simple, secure and scalable solution that can be maintained by IT personnel and extended in the future according to the organization's requirements.
